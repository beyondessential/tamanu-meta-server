Machine navigation

Two questions, shown together because they answer each other: whether the detail view is machine-first like the edit form, and whether the fleet gains a machine list. Indicators follow the status page: a dot is an application's health, an enclosure is a machine, and an enclosure is drawn only where a machine is the subject.

Group listing

The group page lists its servers grouped by rank. With machines, either the rows stay flat and name their machine, or shared machines enclose their applications.

Machine list

Servers has tabs for Groups, Ungrouped, Archived, Figures. A Machines tab would sit among them and answer "what is on this box", which no current view does.

Earns its place only if machines are worth listing on their own. It is where a fleet-wide "which boxes are on old bestool" or "which are shared" gets answered, and the natural landing place if the detail view goes machine-first. If the detail view stays application-first, this tab is a second index of the same fleet.

The indicator column is the same enclosure the status page uses, so the row count of dots reads as the workload on that box. Tonga's orange pill is a machine whose own checks are warning while all three applications on it are fine, which is a state no current view can show.
